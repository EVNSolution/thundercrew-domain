다음 고객 위치 입력 방식

클리닝 차량 시뮬레이션의 목적지가 됩니다

A

주소 텍스트 입력 → 자동 좌표 변환

관리자가 주소를 입력하면 카카오/네이버 지도 API로 자동 변환

장점

  • 사용하기 쉬움
  • 실제 주소로 관리 가능

단점

  • 지오코딩 API 추가 연동 필요
  • 구현 복잡도 높음
B

위도/경도 직접 입력

관리자가 lat / lng 값을 직접 입력 (예: 37.5665 / 126.9780)

장점

  • 구현 간단
  • 외부 API 불필요

단점

  • 좌표를 직접 알아야 함
  • 실무에서 불편
C

주소 텍스트 + 위도/경도 (추천)

주소(메모용) + lat/lng 직접 입력. Google Maps에서 좌표 복사해서 붙여넣기

장점

  • 외부 API 없이 빠르게 구현
  • 주소도 기록으로 남음
  • 구글맵에서 좌표 쉽게 복사 가능

단점

  • 좌표 직접 입력 다소 번거로움
